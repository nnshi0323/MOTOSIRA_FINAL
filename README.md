# MOTOSIRA
**Motorcycle Sound-based Identification & Reporting Assistant** — Team 16, BS Computer Engineering, Holy Angel University.

Portable acoustic diagnostic device: an INMP441 microphone on a Raspberry Pi 4 records engine sound, MFCC
features are classified by a Random Forest into **Normal, Knocking, Misfire, Valve Ticking** for the
Honda TMX 125 Alpha (primary), Rusi Macho 125 and Suzuki Smash Carb. Results appear on the Pi's 3.5" LCD and a
web dashboard, with session logging and PDF/CSV reports.
